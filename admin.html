FAQ Halaman (opsional)

Pratinjau Situs

Pratinjau ini menampilkan beranda situs dengan perubahan yang telah Anda simpan pada browser ini.

Ekspor / Impor Data

Semua perubahan sudah live otomatis lewat tombol "Simpan..." di tiap tab (tersimpan ke database). Alat di bawah ini untuk cadangan/backup opsional saja.

Unduh Cadangan (Backup)

Unduh data.js berisi salinan data saat ini sebagai arsip/cadangan pribadi. Tidak perlu diupload ke mana pun — data live sudah otomatis tersimpan di database sejak Anda menekan tombol "Simpan...".

JSON Mentah

Reset

Mengembalikan seluruh data pada pratinjau browser ini ke nilai bawaan situs.

Keamanan

Ganti password login halaman admin ini (proteksi Basic Auth). Perubahan langsung berlaku di server, tidak perlu unduh/upload file apa pun.

Ganti Password Login

Catatan: setelah berhasil diganti, browser Anda mungkin masih menyimpan password lama sampai ditutup dan dibuka kembali (perilaku bawaan Basic Auth, bukan bug) — gunakan password baru saat diminta login ulang.
